── 이 스킬이 하는 것 ──

HTML 마크업과 Figma 디자인 양쪽의 접근성을 검수합니다.
WCAG 2.1 AA + KWCAG 2.2 기준으로 문제를 찾고 수정 방법까지 제안합니다.


── HTML 검수 ──

검수할 파일이나 코드를 Claude에게 전달하고 아래처럼 요청합니다.

  "접근성 검수해줘"
  "WCAG 체크해줘"
  "키보드 접근성 확인해줘"
  "스크린리더 대응해줘"

검사 항목:
  - 이미지 alt 속성
  - 색상 대비 (텍스트 4.5:1 / UI 요소 3:1)
  - 키보드 접근성 (tab, enter, space)
  - 포커스 표시 (outline 제거 여부)
  - 건너뛰기 링크 (#skipnavi)
  - 폼 레이블 연결
  - ARIA 올바른 사용
  - 모달 포커스 트랩 및 복귀
  - 터치 타깃 44×44px 이상
  - heading 계층 순서


── Figma 디자인 검수 ──

Figma 화면 링크 또는 스크린샷을 전달하고 요청합니다.

  "figma 접근성 확인해줘"
  "디자인 접근성 검수해줘"
  "색상 대비 확인해줘"

검사 항목:
  - 텍스트·배경 색상 대비
  - 컴포넌트 focused state 정의 여부
  - 터치 영역 크기
  - 에러/경고 상태 아이콘+텍스트 병행 여부
  - 자동 재생 모션 처리

  ※ figma-mcp-go 플러그인이 연결되어 있으면 Figma 변수에서
    색상 값을 직접 추출해 대비를 자동으로 계산합니다.


── 결과 출력 형식 ──

검수 결과는 심각도별로 분류해 제공됩니다.

  ❌ Critical — WCAG 위반, 즉시 수정 필요
  ⚠️ Warning  — 수정 권장
  💡 Suggestion — 개선 권장
  ✅ 통과 항목

각 항목마다 WCAG 기준 번호, 위치(라인), 수정 방법을 함께 제시합니다.


── 납품 전 체크리스트 ──

전체 파일 검수 없이 빠르게 체크만 할 때:

  "납품 전 접근성 체크리스트 확인해줘"

HTML + 디자인 항목을 한 번에 체크리스트 형식으로 확인합니다.
